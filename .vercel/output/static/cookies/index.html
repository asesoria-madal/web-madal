Política de cookies

Esta web no usa cookies de analítica ni de publicidad

No instalamos cookies para seguirte, mostrarte anuncios personalizados ni analizar tu comportamiento individual.

Medición de visitas

Usamos Vercel Web Analytics para saber cuántas visitas recibe la web y qué páginas se leen más. Esta herramienta no usa cookies ni identificadores que permitan reconocerte entre visitas: los datos se agregan de forma anónima. Por eso no te pedimos consentimiento para esto.

Si esto cambia

Si en el futuro incorporamos herramientas que sí usen cookies (por ejemplo, para publicidad), actualizaremos esta página y añadiremos un aviso para que puedas aceptarlas o rechazarlas antes de que se activen.
