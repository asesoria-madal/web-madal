# Asesoría Madal — guía para agentes

Este archivo describe el sitio para agentes de IA y navegadores automatizados. Para un resumen orientado a modelos de lenguaje, ver [/llms.txt](https://asesoriamadal.es/llms.txt).

## Qué es este sitio

Asesoría Madal es una gestoría online (contabilidad y fiscalidad para autónomos, SL y pymes en España). El sitio es informativo y de captación: no hay carrito de compra, checkout ni transacciones automatizadas.

## Acciones disponibles para un agente

- Leer contenido informativo (servicios, precios orientativos, blog fiscal, preguntas frecuentes).
- Rellenar el simulador de precio en [/simulador](https://asesoriamadal.es/simulador) (no envía datos a un tercero, solo calcula una estimación en el navegador).
- Rellenar el formulario de alta en [/alta](https://asesoriamadal.es/alta) para solicitar el servicio.
- Iniciar sesión en el portal de clientes en [/portal](https://asesoriamadal.es/portal) (requiere una cuenta ya existente; no hay registro de autoservicio abierto).

## Lo que este sitio NO permite a un agente

- No hay pago ni contratación totalmente automatizada: toda alta pasa por revisión humana antes de formalizarse.
- No hay API pública ni endpoint MCP en este dominio.
